## What it does

`main.ts` writes one original line of plain text — a review of planet Earth left by an alien tourist — to `/output/entry.txt`. The line is at most 200 characters, a single line, and reads like a real tourist review with a verdict and a rating.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22+, standard library only, deterministic, no network.
